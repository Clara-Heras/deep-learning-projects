# Deep Learning Projects

Proyectos de redes neuronales con TensorFlow y Keras.

- [Clasificación de imágenes CIFAR-10](cifar10-cnn/): CNN desde cero, transfer learning y fine-tuning con MobileNetV2, y explicabilidad con GradCAM.
- [β-VAE sobre Fashion-MNIST](fashion-mnist-vae/): autoencoder variacional y efecto de β en la calidad de reconstrucción.
- [Clasificación de dígitos MNIST](mnist-mlp/): comparación de perceptrones multicapa con distinto número de capas, neuronas y learning rate.

Todos los datasets se descargan automáticamente desde Keras. Para instalar las dependencias:

    pip install -r requirements.txt
